## overview

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/1.gif)

Northstar is a distributed moderation system designed for large Minecraft networks, enabling real-time reporting, punishment syncing, and cross-server admin control.

Built for 1.20.4 and proxy-based architectures.

---

## features

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/2.gif)

- cross-server reporting system  
- global moderation actions (mute, ban, kick)  
- real-time sync via proxy layer  
- lightweight backend design  
- audit-friendly moderation logs  
- scalable network support  

---

## compatibility

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/3.gif)

- Minecraft 1.20.4  
- Velocity proxy integration  
- multi-server networks  
- Paper / Spigot / Purpur backend servers  

---

## installs

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/4.gif)

Deploy across your network:

- install proxy module on Velocity  
- install backend plugin on servers  
- connect via configuration keys  
- restart network services
